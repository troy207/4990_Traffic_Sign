For this project we trained an AI model to detect occlusions in road signs and not only detect road signs, but pedestrains, cars, etc. 

Here is the link to the dataset we made and the trained model that we built: https://www.kaggle.com/datasets/fizzyyyy/4990-road-sign-final-project

To run a test open the Scripts file under YOLO26_Project.zip, open occlusion.py and set the file path to the image you want to detect, then save and run, for videos, do the same process but use vocclusion.py
